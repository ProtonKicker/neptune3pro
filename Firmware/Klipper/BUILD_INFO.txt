## First flash (stock Marlin -> Klipper, manual SD required)
1. Format SD as MBR + single FAT32 partition (printer ignores ExFAT).
2. Copy ZNP_ROBIN_NANO.bin to SD root, safely eject.
3. Printer OFF -> insert SD -> power ON. Screen shows UPGRADE FIRMWARE
   with stuck progress bar (normal). Wait ~2 min.
4. Power OFF -> remove SD -> unplug stock touchscreen ribbon -> power ON.
5. Connect USB to Mac, run: klipperformac serial --auto && klipperformac up
